## 1. Reference Architecture

```

        │
        ▼  (webhooks / Kafka event bus)
┌────────────────────────────────────────────────────────────┐

│                                                            │
│  LangGraph Supervisor (StateGraph, hierarchical)           │
│   ├── Triage subgraph        ├── Diagnose loop subgraph    │
│   ├── Plan subgraph (RAG)    ├── Approval gate (interrupt) │
│   ├── Execute subgraph       ├── Verify subgraph           │
│   └── Learn subgraph (writeback)                           │
│   PostgresSaver checkpointer (durable, resumable, replay)  │
└────────────────────────────────────────────────────────────┘
     │                  │                    │
     ▼                  ▼                    ▼
 pgvector store     Tool mesh (HTTP/gRPC)   LLM + embedder
 (runbooks,         read tools (Python)     (vLLM + TEI on-prem
 postmortems,       write tools (Go gateway  GPU nodes — air-gap
 logs, alerts,      + OPA allowlist,         friendly)
 CVEs, policies)    dry-run enforced)
```

**Why LangGraph:** cyclic state machines (diagnose loops), durable execution via PostgreSQL checkpointer (survive pod restarts mid‑incident), first‑class human‑in‑the‑loop `interrupt()`, subgraph composition per domain, and time‑travel replay for auditing agent decisions.

**Why pgvector:** one Postgres instance serves three roles — (1) vector knowledge base (RAG over runbooks/postmortems/KBs), (2) semantic memory (incident similarity, episodic memory), (3) LangGraph checkpoint store. Hybrid search (SQL filters + vector + full‑text RRF) with HNSW indexes gives sub‑50ms retrieval at millions of chunks.

## 2. The Universal Agent Skeleton (all use cases instantiate this)

Every use case below is the same graph shape — **Perceive → Retrieve → Reason (loop) → Plan → Approve → Execute → Verify → Learn**:

```python
from typing import TypedDict, Annotated
import operator
from langgraph.graph import StateGraph, START, END
from langgraph.types import interrupt, Command
from langgraph.checkpoint.postgres import PostgresSaver

class SREState(TypedDict):
    alert: dict                      # event/alert/trigger payload
    similar: list[dict]              # pgvector retrieval results
    hypothesis: str
    findings: Annotated[list, operator.add]   # accumulates tool evidence
    rca: str
    plan: list[dict]                 # remediation steps w/ risk + rollback
    approval: str
    execution_log: list[dict]
    verified: bool
    escalated: bool

def perceive(state): ...             # normalize alert, map CI/component
def retrieve(state): ...             # pgvector: similar incidents + runbooks
def diagnose(state): ...             # LLM proposes hypothesis, calls read-tools, loops
def plan_remediation(state): ...     # RAG runbook -> concrete steps + rollback
def approve(state):
    if risk(state) > THRESHOLD:      # interrupt() pauses graph, persists state
        decision = interrupt({"plan": state["plan"], "risk": risk(state)})
    else:
        decision = "auto"
    return {"approval": decision}
def execute(state): ...              # dry-run first, then real via Go gateway
def verify(state): ...               # check SLIs/SLOs returned to normal
def learn(state): ...                # embed outcome back into pgvector

g = StateGraph(SREState)
g.add_node("perceive", perceive); g.add_node("retrieve", retrieve)
g.add_node("diagnose", diagnose); g.add_node("plan", plan_remediation)
g.add_node("approve", approve); g.add_node("execute", execute)
g.add_node("verify", verify); g.add_node("learn", learn)

g.add_edge(START, "perceive"); g.add_edge("perceive", "retrieve")
g.add_edge("retrieve", "diagnose")
g.add_conditional_edges("diagnose", lambda s: "hypothesis_confirmed" if s["rca"] else "iterate",
                        {"hypothesis_confirmed": "plan", "iterate": "diagnose"})
g.add_edge("plan", "approve")
g.add_conditional_edges("approve", lambda s: s["approval"],
                        {"auto": "execute", "approved": "execute", "denied": END})
g.add_edge("execute", "verify")
g.add_conditional_edges("verify", lambda s: "ok" if s["verified"] else "rollback",
                        {"ok": "learn", "rollback": "execute"})   # bounded retries
g.add_edge("learn", END)

graph = g.compile(checkpointer=PostgresSaver.from_conn_string(PG_DSN))
```

**Autonomy levels (applied per use case):**

| Level | Behavior |
|---|---|
| **L0** | Read‑only diagnosis; posts RCA/suggestion to Slack/ticket |
| **L1** | Auto‑executes low‑risk actions (pod restart, PVC resize) with rollback |
| **L2** | `interrupt()` approval gate (node drain, VM migration, cert rotation) |
| **L3** | Change‑window + CAB approval (cluster upgrades, OVN changes) |
